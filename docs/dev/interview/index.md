  

### **一、前端基础知识（必刷）**

**核心领域**：HTML/CSS、JavaScript、浏览器原理、网络协议、性能优化。  

**高频题目示例**：

1. **HTML/CSS**  

   - 盒模型、Flex/Grid布局、BFC、居中对齐方案。  

   - 响应式设计（媒体查询、REM vs EM）、CSS选择器优先级。  

   - 伪类与伪元素区别、CSS动画（transition/animation）。  

2. **JavaScript**  

   - 闭包、作用域链、原型链、this指向、Event Loop。  

   - Promise/Async Await、手写防抖（debounce）与节流（throttle）。  

   - ES6+特性（箭头函数、解构赋值、Proxy、模块化）。  

3. **浏览器与网络**  

   - 跨域解决方案（CORS、JSONP、代理）、Cookie/Session/Token。  

   - 浏览器渲染流程（重绘与重排）、缓存策略（强缓存/协商缓存）。  

   - HTTP/HTTPS、TCP三次握手、WebSocket、CDN原理。  

4. **性能优化**  

   - 减少重绘重排、代码分割、懒加载、预加载。  

   - Webpack优化（Tree Shaking、Code Splitting）、首屏加载优化。  

  

**推荐资源**：  

- 《JavaScript高级程序设计》（红宝书）  

- MDN Web Docs（权威文档）  

- 前端面试题库：[Front-End-Interview-Questions](https://github.com/h5bp/Front-end-Developer-Interview-Questions)

### **二、算法与数据结构（重点突破）**

**目标**：掌握常见算法题型，提升代码手写能力。  

**必刷题型**：  

1. **基础算法**  

   - 数组操作：两数之和、合并区间、螺旋矩阵。  

   - 字符串处理：反转字符串、最长无重复子串、括号匹配。  

   - 链表：反转链表、环形链表、合并有序链表。  

2. **高频算法**  

   - 栈与队列：最小栈、用栈实现队列。  

   - 二叉树：遍历（前/中/后序）、对称二叉树、最大深度。  

   - 动态规划：爬楼梯、最长递增子序列、背包问题。  

3. **进阶题目**  

   - 图：岛屿数量、课程表（拓扑排序）。  

   - 设计题：LRU缓存、实现Promise.all。  

  

**推荐平台**：  

- **LeetCode**：按标签刷题（数组、字符串、链表等）。  

- **CodeTop**：查看大厂高频题目（如字节跳动、腾讯题库）。  

- **目标建议**：至少刷完 **《剑指Offer》** 和 **LeetCode Hot 100**。

### **三、框架与工具（React/Vue为主）**

**核心考点**：框架原理、状态管理、工程化实践。  

**高频题目示例**：  

1. **React**  

   - 生命周期、Hooks原理（useState/useEffect依赖追踪）。  

   - 虚拟DOM与Diff算法、Fiber架构。  

   - 状态管理（Redux/Mobx）、性能优化（memo/PureComponent）。  

2. **Vue**  

   - 响应式原理（Object.defineProperty vs Proxy）。  

   - 组件通信（props/emit、provide/inject、Vuex）。  

   - 编译过程（模板转AST）、Vue3 Composition API。  

3. **工程化**  

   - Webpack配置（Loader/Plugin）、Babel原理。  

   - 微前端（qiankun）、SSR（Next.js/Nuxt.js）。  

  

**推荐资源**：  

- React官方文档（Hooks部分重点看）。  

- Vue官方文档（响应式原理章节）。  

- 框架源码解析（如《React技术揭秘》）。

### **四、系统设计与项目经验**

**核心目标**：展示复杂场景下的设计能力与项目深度。  

1. **系统设计题**  

   - 设计一个前端组件（如轮播图、虚拟滚动列表）。  

   - 状态管理方案（Redux vs Context API选型）。  

   - 前端监控系统（错误采集、性能上报）。  

2. **项目复盘**  

   - 使用 **STAR法则** 描述项目：背景（Situation）、任务（Task）、行动（Action）、结果（Result）。  

   - 准备技术难点：如性能优化从5s降到1s的具体措施。  

   - 量化成果：如“通过懒加载减少首屏资源体积30%”。  

  

**推荐准备**：  

- 梳理1-2个核心项目，明确技术亮点。  

- 模拟设计题：[Grokking the System Design Interview](https://www.educative.io/courses/grokking-the-system-design-interview)。
